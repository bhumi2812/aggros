Database Setup Guide

Note: This application requires a MySQL database to function properly. Follow the steps below to set up the database.

Step 1: Install MySQL (if not already installed)

If you don't have MySQL installed, you'll need to install it first:

  • Download MySQL Installer
  • Run the installer and follow the instructions
  • Make sure to remember the root password you set during installation

Step 2: Update Database Connection Settings

If your MySQL installation uses different credentials than the defaults, you'll need to update the connection settings in the application:

  1. Open the file src/main/java/com/pesticides/util/DBUtil.java
  2. Update the following constants if needed:
    • DB_URL - The URL of your MySQL server (default: "jdbc:mysql://localhost:3306/agros_db")
    • DB_USER - Your MySQL username (default: "root")
    • DB_PASSWORD - Your MySQL password (default: "root")

Step 3: Initialize the Database

Once MySQL is installed and the connection settings are updated, you can initialize the database:

  1. Make sure your application is running
  2. Visit the following URL in your browser: Initialize Database
  3. This will create the necessary database and tables

Step 4: Verify the Database Setup

After initializing the database, you can verify that everything is set up correctly:

  1. Visit the following URL in your browser: Test Database Connection
  2. This page will show you if the database connection is working and if the tables have been created

Step 5: Start Using the Application

Once the database is set up, you can start using the application:

  1. Visit the following URL in your browser: Product Management
  2. You should now be able to add, edit, and delete products

Troubleshooting

If you encounter any issues, check the following:

  • Make sure MySQL is running
  • Verify that the connection settings in DBUtil.java are correct
  • Check the application logs for any error messages
  • If you get a "Unknown database" error, make sure you've initialized the database by visiting the Initialize Database URL
